# TelePost 投稿审核规则模板

> 这是管理员可直接修改的审核规则。AI Agent 只应依据本文件给出建议；本文件没有明确规定时，选择 `needs_human_review`，不要自行制定频道价值标准。

## 频道主题

- 在此填写频道允许的主题范围。
- 在此填写明显偏离主题的内容类型。

## 允许内容

- 例：与频道主题相关的原创或授权转载作品。
- 例：标题、标签、来源链接信息完整。

## 不允许内容

- 违法、侵权或无法证明授权的内容。
- 恶意软件、钓鱼、引流欺诈、仇恨或骚扰内容。
- 与频道主题无关的广告或推广。

## 广告与引流

- 说明哪些外链、水印、社群推广、个人主页链接可以接受。
- 说明哪些形式必须拒绝或要求人工复核。

## 转载与版权

- 接受转载的条件：作者授权、来源许可、公共领域或合理使用证据。
- 缺少来源、作者或许可证据时的处理方式。

## 图片与媒体质量

- 最低清晰度、裁切、水印、压缩、重复图片要求。
- 视频/GIF 的清晰度、时长、封面和声音要求。

## 重复投稿

- 同一作品、同一来源链接或同一 idempotency key 的处理方式。
- 已发布、已拒绝、换图重投时的处理方式。

## 标签、标题与备注

- 标签数量、语言、命名规范。
- 标题和备注允许包含的信息；禁止 Telegram/HTML 注入式格式。

## NSFW / Spoiler

- 哪些内容必须开启 spoiler。
- 哪些内容必须拒绝，而不是仅开启 spoiler。
- 边界内容默认转人工。

## 拒绝原因规范

- 用简短、具体、不带侮辱性的语言说明原因。
- 不暴露内部 token、用户隐私或系统细节。

## 边界情况

以下情况默认 `needs_human_review`：

- 政策没有明确规定。
- 版权、年龄限制、广告属性或真实性无法判断。
- 媒体预览不完整、视频封面无法代表内容。
- Agent 置信度不足或不同规则相互冲突。
